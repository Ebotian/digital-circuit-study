0导读：单输出之后

讲义二结束在一个不太舒服的地方：单输出综合有判据、有闭式算法、也有明确的墙；但真实电路很少只有一个输出。

一个译码器有 $2^n$ 个输出，一个 ALU 有结果、进位、零标志、溢出标志，一条总线上的每个接收端都可能是不同的函数。于是研究对象从

$$\Phi:\ \text{电路}\ \longrightarrow\ \text{一个函数}$$

变成了

$$\Phi:\ \text{电路}\ \longrightarrow\ (f_1,f_2,\dots,f_m).$$

这不是把单输出算法跑 $m$ 遍。多输出电路的第一性事实是：输出可以共享内部结构。

本册的两条主线

共享：同一个反相器、乘积项、内部节点、连线，可以同时服务多个输出。

部分规范：三态输出允许“不驱动”，于是规范不再是完整的布尔函数，而是一个部分函数。

单输出（讲义二）多输出（本册）
优化对象一个函数一个函数元组 + 一个共享网络
成本一个网络的成本共享子图的成本，可能被 fanout 反噬
最优性单级有闭式；多级已很难一般是 NP-hard 的组合问题
“证明”在明确模型内更要说清楚模型，否则 proof 没有意义

这一册先讲组合多输出。时序、状态和反馈留到下一册；但这里建立的“网络而非函数”的视角，会直接用在时序网络上。

1多输出不是多个单输出

先看一个最小的反例。给定两个输出：

$$Y_0=\bar A\bar B,\qquad Y_1=\bar A B.$$

如果分别综合，两个电路都要自己造一个 $\bar A$。如果放在一起，$\bar A$ 只造一次，扇出到两个门。管数立刻不同。

更准确地说，一个多输出网络是：

$$\mathcal{N}=(V,E),\qquad \text{输出集合 } O\subseteq V.$$

每个输出 $o\in O$ 上观察到一个函数 $f_o$。成本是

$$C(\mathcal{N})=\sum_{e\in E} c_e,$$

而不是 $\sum_o C(f_o)$。这就是差别：成本定义在网络上，函数只是网络端点的读数。

本册的中心句

多输出综合的最小单位不是函数，而是网络。
“把这几个函数分别最小化”通常会错过共享，也通常不是最优。

这也解释了为什么讲义二里的 $\Phi^{-1}(f)$ 不够用：$\Phi^{-1}(f_1,\dots,f_m)$ 是一个网络集合，而集合里的网络成本不同。函数元组本身不携带“它们可以怎样共享”的信息。

2手算 2-to-4：20T 从哪里来

2-to-4 译码器的真值表：

$A$$B$$Y_0$$Y_1$$Y_2$$Y_3$
001000
010100
100010
110001

输出是四个 minterm：

$$\begin{aligned} Y_0&=\bar A\bar B\\ Y_1&=\bar A B\\ Y_2&=A\bar B\\ Y_3&=AB \end{aligned}$$

2.1 直觉做法：四个 AND2，为什么不是最优

静态互补 CMOS 的基本输出天然反相：

$$Y=\overline{f_{\mathrm{pd}}}.$$

所以 AND2 不能直接用一个单级门实现，它需要：

$$\text{AND2}=\text{NAND2}+\text{INV}=4T+2T=6T.$$

四个 AND2，加上共享的 $\bar A,\bar B$：

4 × AND2        24T
2 × INV          4T
--------------------
合计             28T

但这不是唯一写法。

2.2 换个写法：NOR2

把每个 minterm 写成“或的非”：

$$\begin{aligned} Y_0&=\bar A\bar B=\overline{A\vee B}=\operatorname{NOR2}(A,B)\\ Y_1&=\bar A B=\overline{A\vee\bar B}=\operatorname{NOR2}(A,\bar B)\\ Y_2&=A\bar B=\overline{\bar A\vee B}=\operatorname{NOR2}(\bar A,B)\\ Y_3&=AB=\overline{\bar A\vee\bar B}=\operatorname{NOR2}(\bar A,\bar B) \end{aligned}$$

于是：

部分数量每个小计
共享反相器 $\bar A,\bar B$22T4T
NOR2 输出门44T16T
总计20T（10N + 10P）

这就是工具在“单级静态复杂 CMOS + 共享输入反相器”模型内证明的最优值：

$ ./build/dcstudy multi exact --spec /tmp/demux4.json --json
20T  (10 NMOS + 10 PMOS)
proof: true
model: single-stage static complex CMOS with shared input inverters
为什么 NOR 反而更便宜

不是因为 NOR 比 AND “更基础”，而是因为静态 CMOS 的输出已经是反的。译码器的每个输出只在一个 minterm 为 1；这个 minterm 的“或”形式正好是 NOR 的输入。用 AND 等于先造一个反相输出，再把它反回来。

33-to-8：54T 与共享轨

把 2-to-4 的规律直接推广。3 个输入产生 8 个 minterm：

$$Y_i=\bigwedge_{j=0}^{2}\ell_{ij},\qquad \ell_{ij}\in\{A_j,\bar A_j\}.$$

静态 CMOS 输出反相，所以每个 $Y_i$ 写成“或的非”：

$$Y_i=\overline{\bigvee_{j=0}^{2}\bar\ell_{ij}} =\operatorname{NOR3}(\text{三个适当极性的输入}).$$

例如：

$$\begin{aligned} Y_0&=\bar A\bar B\bar C=\operatorname{NOR3}(A,B,C),\\ Y_7&=ABC=\operatorname{NOR3}(\bar A,\bar B,\bar C). \end{aligned}$$

电路就是：

3 个共享反相器:  A' , B' , C'       3 × 2T = 6T
8 个 NOR3:                          8 × 6T = 48T
------------------------------------------------
总计                                      54T
(27 NMOS + 27 PMOS)

工具结果：

$ ./build/dcstudy multi exact --spec /tmp/decoder38.json --json
54T  (27 NMOS + 27 PMOS)
proof: exhaustive over all 8 inverter sets + exact minimum DNF per output
model: single-stage static complex CMOS with shared input inverters

3.1 一般公式

对 $n\to 2^n$ 译码器，在“$n$ 输入 NOR 可用”的单级模型里：

$$T(n)=2n+2^n\cdot 2n=2n\left(1+2^n\right).$$
$n$输出数反相器NOR 门总晶体管
244T4 × 4T20T
386T8 × 6T54T
4168T16 × 8T136T

注意：这个公式假设 $n$ 输入 NOR 是一个单元。真实标准库里 NOR 的 fan-in 有限，$n$ 大时必须拆成多级；那时 54T 这种“单级证明”就不再适用。

3.2 共享轨的画法

把 54T 网络画出来，最重要的不是 8 个 NOR3，而是左边那 6 根输入/反相轨：

 A   A'   B   B'   C   C'
 |    |    |    |    |    |
 +----+----+----+----+----+----  Y0 = NOR3(A,B,C)
 +----+----+----+----+----+----  Y1 = NOR3(A,B,C')
 +----+----+----+----+----+----  Y2 = NOR3(A,B',C)
 ...                         ...
 +----+----+----+----+----+----  Y7 = NOR3(A',B',C')

每一行从三根轨上取三个字面量。这个结构在 Mano 的译码器图里就是“输入反相器 + 与门阵列”；在静态 CMOS 里，与门换成了 NOR3，因为输出极性被反了一次。

别把“共享轨”只当成画图技巧

共享轨意味着一根输入线要驱动 8 个门的栅极。逻辑上这是免费的；物理上它是 fanout、电容和延时的来源。54T 只数晶体管，不数这些代价。

4共享的四个层次

“共享”不是一个开关，而是分层的。越往下，优化越难，也越容易被逻辑等价性掩盖。

层次共享什么例子工具里的位置
1输入反相器 / 字面量$\bar A,\bar B,\bar C$multi exact 显式建模
2乘积项 / 子表达式$AB$ 同时进入两个输出多级综合、ABC
3内部节点 / 路径两条 source-to-sink 路径共享前缀multi path 的 edge 共享
4输出驱动 / 总线多个三态门接同一根 bus--tri-state + 唯一驱动约束

4.1 共享不是无条件划算

假设两个输出都要 $AB$，共享一个 AND 门看起来省了 4T。但共享节点的 fanout 变成 2，驱动能力、连线电容、布局拥塞都增加；在真实 PDK 上，复制一个门有时更快、更小。

所以多输出优化的目标不应该写成“晶体管数最少”，而应该写成：

$$\min_{\mathcal{N}}\ \sum_e c_e \quad\text{s.t.}\quad \text{对所有输入，所有输出都正确}.$$

这里的 $c_e$ 可以是晶体管数、面积、延时、功耗，或者它们的加权和。换一个 $c_e$，最优网络就可能换一个。

5一般问题：共享子图

把开关网络抽象成有向图 $G=(V,E)$。每条边有：

  • 类型：N / P / TG；
  • 导通条件：一个字面量或常量 1；
  • 成本 $c_e$；
  • 源/漏端点。

多输出路径问题可以说成：

问题（多输出路径选择）

给定图 $G$、输入变量 $X$、输出集合 $O$，以及每个输出在每个输入下应驱动的值，选择边集 $H\subseteq E$，使得：

  1. 每个输出 $o$ 在 $H$ 中有一条从源到 $o$ 的路径；
  2. 对每个输入 $x$，每个输出最多有一个驱动源；
  3. 被驱动的输出值等于规范；未被驱动的输出允许为 $Z$（仅三态模式）；
  4. $H$ 的总成本最小。

这是一个带路径约束的有向 Steiner 森林。它同时包含：

  • Steiner 树：共享前缀边；
  • 多商品流：每个输出是一条 commodity；
  • 逻辑约束：路径的导通条件是字面量乘积；
  • 驱动约束：同一时刻不能有两个源对拉。

一般情形是 NP-hard 的。所以工具不是一个“万能最优器”，而是几种不同模型的组合：

命令模型保证
multi exact每输出一个单级静态复杂 CMOS 门；共享输入反相器；无门间共享在该模型内穷举证明
multi path路径变量；多个输出共享 switch edge；唯一驱动在给定路径图内搜索；proof 表示搜索是精确的
multi template有限候选图 / 模板边≤20 边精确；否则贪心，proof=false
multi synthYosys/ABC 多输出映射启发式，不证明最优

5.1 双轨路径：PUN 和 PDN 分别搜索

无三态时，一个输出不能靠“某条路径恰好导通”来碰运气；它必须满足互补条件：

  • 输出为 1 的行，只能由一条从 1 到 $Y$ 的 PUN 路径强驱动；
  • 输出为 0 的行，只能由一条从 0 到 $Y$ 的 PDN 路径强驱动；
  • PUN 路径不得在应输出 0 的行导通，PDN 路径不得在应输出 1 的行导通。

实现上把每轨的目标向量写成“本轨负责的值 / 对侧为 $-1$”，分别跑路径覆盖搜索；再枚举输入反相器集合，取两轨并集的成本。验证时不能把两个源直接塞进同一个无向开关图：从 $0$ 出发可以穿过 $Y$ 再沿 PUN 反向走到 $1$，制造假通路。正确做法是每个输出、每轨单独建图，把输出当作 sink，对侧行标成高阻无关项。

双轨结果

1-to-4 分路器：14T；3-to-8 译码器：26T。两者都是无三态、每个输出始终驱动 0/1，proof: true（在路径图模型内）。

为什么不能写一个 decoder 特例

译码器只是一个 spec 实例：输出是 one-hot 的 minterm 集合。把 if (name == "decoder") 写进工具，能过测试，却学不到共享结构，也无法处理编码器、分路器、总线、任意多输出函数。通用算法应当把译码器当作输入，而不是当作分支。

6三态：规范变了

普通布尔输出只有 $0,1$。三态输出多了一个 $Z$：

$$Z=\text{不驱动（高阻）}.$$

对译码器来说：

输入普通静态输出三态输出
$i$ 被选中选中输出 = 1，其余 = 0选中输出 = 1，其余 = $Z$
$i$ 未被选中必须主动拉到 0不驱动，允许浮空

这不是“更省面积的译码器”，而是规范从函数变成了部分函数：

$$f:S\longrightarrow\{0,1\},\qquad S\subseteq\{0,1\}^n.$$

在 $S$ 内必须给出 0/1；在 $S$ 外不要求驱动。

6.1 驱动集判据

对每个输出 $o$ 和输入 $x$，令 $D_o(x)$ 为把输出拉到 0 或 1 的驱动源集合。良构性要求：

$$|D_o(x)|\le 1,$$

并且如果 $x\in S$，则 $|D_o(x)|=1$ 且值正确。

  • $|D|=0$：高阻，三态模式允许；
  • $|D|=1$：正常驱动；
  • $|D|\ge 2$：冲突，两个源对拉，禁止。

三态并没有放松“不能冲突”这一条；它只放松了“未被选中时必须为 0”。

6.2 工具数字

3-to-8 decoder, --tri-state:
16T = 12T switch + 4T inverters

1-to-4 demux, --tri-state:
6T  = 4T switch + 2T inverter

同一个 1-to-4 demux，无三态:
20T  单级静态复杂 CMOS (2 INV + 4 NOR2)
14T  PUN/PDN 双轨路径搜索

同一个 3-to-8 decoder，无三态:
54T  单级静态复杂 CMOS
26T  PUN/PDN 双轨路径搜索

三态把未选中的输出从“必须拉 0”改成“可以不驱动”，所以能更省。双轨搜索则保持 0/1 驱动，但允许路径从 VDD/VSS 直接选通，因此在同一个无三态规范下也能比“每输出一个单级静态门”更省。

三态不是免费的

高阻节点会浮空。真实总线需要 keeper、pull-down 或接收端定义；多个三态驱动器接在同一根线上时，必须保证同一时刻最多一个使能。路径模型里的“唯一驱动”约束，就是这件事的形式化。

7.1 proof 是一个条件句

看到 proof: true 时，正确的读法是：

在工具明确写出的模型内，没有比这个更便宜的解。

它不是：

在全宇宙的所有电路里，这是最便宜的。

54T 的模型排除了：

  • 传输门 / pass transistor；
  • 输出之间的门共享；
  • 输出反相器；
  • 多级分解；
  • 三态；
  • fanout、连线、延时、功耗。

双轨路径在无三态模型内把同一个 3-to-8 译码器从 54T 降到 26T；再放开三态，又降到 16T。这不是“54T 算错了”，而是模型不同。

读 EDA 论文的第一句话

不要先看它报了多少面积、多少延时；先看它的模型允许什么、禁止什么。
“最优”在 EDA 里几乎总是“在某套约束下最优”。

7.2 成本模型只数晶体管

20T / 54T / 14T / 26T / 16T / 6T 都是晶体管数。它们没有回答：

  • 共享反相器的 fanout 是否让延时变差；
  • NOR3 的串联 PMOS 是否比 NAND3 慢；
  • 三态总线的电容和 keeper 是否抵消了管数优势；
  • 布局后连线是否成为瓶颈。

讲义二第 8 章已经用真实 PDK 展示过：面积、漏电、延时、功耗，对同一个逻辑可以给出完全不同的排序。多输出只是把这个问题放大：共享在逻辑层省钱，在物理层可能收费。

8练习

题 1　用 2 个共享反相器和 4 个 NOR2 画出 2-to-4 译码器，并解释：

  • 为什么 $Y_0=\operatorname{NOR2}(A,B)$；
  • 为什么不能直接用一个 AND2 实现 $Y_0$；
  • 20T 里哪 4T 是共享的。
答案

$Y_0=\bar A\bar B=\overline{A\vee B}$，所以 NOR2(A,B) 只在 $A=B=0$ 时输出 1，正好是 $Y_0$。

AND2 需要先 NAND2 再反相，6T；四个 AND2 是 24T，再加 4T 输入反相器，28T。

共享的 4T 是 $\bar A$ 和 $\bar B$ 两个反相器；四个 NOR2 各自 4T，共 16T。

题 2　把 2-to-4 和 3-to-8 译码器改成低有效输出：被选中的输出为 0，其余为 1。静态 CMOS 版分别要多少晶体管？

答案

低有效输出是 $Y_i=\overline{m_i}$。用 De Morgan，把 NOR 换成 NAND，字面量极性取反即可。

2-to-4：4 个 NAND2（16T）+ 2 个共享反相器（4T）= 20T。

3-to-8：8 个 NAND3（48T）+ 3 个共享反相器（6T）= 54T。

管数不变，变的是输出门的类型和输入轨的极性。这说明“低有效”不是免费的面积优化，它只是把反相搬到了别处。

题 3　两个三态译码器的输出直接接到同一根总线上。什么情况下会出错？这对应路径模型里的哪个约束？

答案

如果两个译码器同时被使能，并且它们的某个输出同时驱动总线（一个拉 1、一个拉 0），就会发生总线争用/对拉。

对应约束是：对每个总线节点、每个输入，驱动源集合 $D(x)$ 必须满足 $|D(x)|\le 1$。三态允许 $|D|=0$，但不允许 $|D|\ge 2$。

工程上还需要 one-hot 使能、互锁逻辑或总线仲裁；形式化只能检查“给定的使能条件下不冲突”，不能替系统设计使能协议。

题 4　为什么 54T 的 proof: true 不等于“3-to-8 译码器的全局最优是 54T”？

答案

因为 54T 只在“单级静态复杂 CMOS + 共享输入反相器 + 无门间共享 + 无 TG/三态”的模型内最优。

一旦允许三态路径，同一个 spec 得到 16T；一旦允许多级或 TG，还可能得到别的解。54T 是这个模型的下界，不是所有电路空间的下界。

所以看到 proof 要先问：模型是什么？被排除的结构有哪些？

题 5（推广）　对 $n\to2^n$ 译码器，单级静态模型的管数公式是什么？$n=4$ 时是多少？这个公式在什么条件下失效？

答案

反相器部分：$n\times 2T=2n$。

NOR 阵列：$2^n$ 个 NORn，每个 NORn 有 $n$ 个 NMOS + $n$ 个 PMOS $=2n$ 个管子，所以是 $2^n\cdot 2n$。

合计：

$$T(n)=2n+2^n\cdot 2n=2n(1+2^n).$$

$n=2$ 给 $4(1+4)=20$，$n=3$ 给 $6(1+8)=54$，$n=4$ 给 $8(1+16)=136$。✓

失效条件：$n$ 输入 NOR 不是单个标准单元（fan-in 限制）、需要多级、允许 TG/三态/输出共享，或者成本不再是晶体管数。

2-to-4 的 spec：

{
  "name": "demux1to4",
  "inputs": ["A", "B"],
  "outputs": [
    {"name": "Y0", "expr": "~A&~B"},

# 单级静态复杂 CMOS：20T，模型内证明
./build/dcstudy multi exact --spec /tmp/demux4.json --json

如果 spec 不在 /tmp，把路径换成你自己的。所有命令都支持 --out DIR --png 出图。

C. 下一章

组合多输出解决的是“同一时刻，多个输出怎么共享”。下一章要加时间：

  • 状态：输出不只依赖当前输入，还依赖历史；
  • 反馈：组合闭包变成带状态的不动点；
  • 时序：latch/FF、时钟、建立/保持；
  • FSM：状态图、状态编码、时序综合；
  • 三态总线：多主设备、仲裁、keeper。

而这一册留下的问题会一直跟着我们：

共享在逻辑层省下的晶体管，什么时候会在物理层还回去？

单输出问“能不能造” · 多输出问“怎么共享” · 三态问“什么时候不驱动”
这三个问题，正好对应综合工具的三层抽象。
